# Personal Expense Tracker 

A simple console-based **Personal Expense Tracker** written in **C++**.  
This application helps users record income, expenses, and savings, and view monthly financial summaries.

This project represents one of my **early learning projects in C++** and marks my **first project uploaded on GitHub**.

---

##  Features
- Record **Income**, **Expense**, and **Saving**
- Store data permanently using **file handling**
- View **monthly transaction history**
- Display **total income, expense, savings, and net balance**
- Simple and clean **menu-driven interface**

---

##  Tech Stack
- **Language:** C++
- **Concepts Used:**
  - Object-Oriented Programming (Classes & Objects)
  - File Handling
  - STL (`vector`, `string`, `stringstream`)
  - Input validation
  - Formatted output
